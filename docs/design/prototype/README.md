# Интерактивный прототип (design canvas)

`Lumi_Prototype.dc.html` — кликабельный прототип экранов Lumi (онбординг,
главная, курсы, урок, магазин и т.д.), собранный в формате Claude's design
canvas ("omelette"/`dc-runtime`). `support.js` и `image-slot.js` — рантайм,
без которого страница не отрендерится.

## Как открыть

Прототип использует `fetch()` (для собственного HTML и для сохранения
изображений в `.image-slots.state.json`), поэтому **не откроется напрямую
через `file://`** — нужен локальный статический сервер:

```bash
cd docs/design/prototype
python3 -m http.server 8000
# затем открыть http://localhost:8000/Lumi_Prototype.dc.html
```

React/ReactDOM/Babel подгружаются с unpkg.com по CDN — нужен доступ в
интернет.

## Ограничения вне omelette-рантайма

- `<image-slot>` (заглушки под изображения маскота/иконок) вне
  редактора Claude доступны только для просмотра — перетащить своё
  изображение и сохранить его не получится (нет `window.omelette.writeFile`
  для записи в `.image-slots.state.json`).
- `support.js` помечен как `GENERATED... do not edit` — это вендоренный
  рантайм, а не код приложения; редактировать его вручную не нужно, при
  необходимости обновить — просто заменить файл целиком.

## Проверено при добавлении в репозиторий

- HTML целостен: 48 `<sc-if>` открыто/закрыто, скобки/скрипты сбалансированы,
  файл не обрублен.
- `screensOrder` (38 экранов) содержит все переходы из сайдбара — экраны,
  недостижимые напрямую через `go.X` в теле (`ex1`, `ex4`, `ex6` и др.),
  всё равно кликабельны из сайдбара (там переходы генерируются динамически
  по `screensOrder`), это не баг.
- **Исправлено**: `<script src="./image-slot.js">` ссылался на файл, который
  был выгружен под именем `imageslot.js` (без дефиса) — переименовал при
  копировании, иначе рантайм слота изображений не подгрузился бы (404).
- `hint-placeholder-count="27"` в сайдбаре (`<sc-for>`) не совпадает с
  реальным числом экранов (38) — это только подсказка для skeleton-анимации
  при стриминге, на функциональность не влияет, но при желании поправить —
  косметика.
