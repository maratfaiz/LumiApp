# Интерактивный прототип (design canvas)

`Lumi_Prototype.dc.html` — кликабельный прототип экранов Lumi (онбординг,
главная, курсы, урок, магазин и т.д.), собранный в формате Claude's design
canvas ("omelette"/`dc-runtime`). `support.js` и `image-slot.js` — рантайм,
без которого страница не отрендерится.

## Структура папки

- `Lumi_Prototype.dc.html` — сам прототип.
- `Icon_Reference.dc.html`, `Lumi_Poses_Brief.dc.html`, `Shop_Items_Brief.dc.html` —
  справочные брифы (не часть прототипа): списки нужных иконок / поз маскота /
  товаров магазина с описаниями для художника или генератора изображений.
- `assets/` — готовый арт маскота и скинов (37 PNG), подключённый в прототипе
  через `src="./assets/…"`.
- `support.js`, `image-slot.js` — вендоренный рантайм (см. ограничения ниже).

## Как открыть

Прототип использует `fetch()` (для собственного HTML и для сохранения
изображений в `.image-slots.state.json`), поэтому **не откроется напрямую
через `file://`** — нужен локальный статический сервер:

```bash
cd docs/design/prototype
python3 -m http.server 8000
# затем открыть http://localhost:8000/Lumi_Prototype.dc.html
```

React/ReactDOM/Babel подгружаются с unpkg.com по CDN — нужен доступ в
интернет.

## Что уже подключено, а что нет

Арт маскота (`assets/mascot-*.png`) подключён у 28 из 43 `<image-slot>` в
прототипе — везде, где для позы уже есть готовое изображение. Без арта пока
остались: 4 иконки курсов (`course-0-icon` … `course-5-icon`), `mascot-crisis`,
`mascot-profile` и 9 товаров магазина (`shop-glasses`, `shop-crown` и т.д.) —
эти слоты показывают текстовую заглушку.

9 скинов (`assets/skin-*.png`: classic, cosmonaut, lucky, musician, night,
scientist, sport, traveler, wizard) в прототипе пока никуда не подключены —
под них ещё нет экрана «Гардероб».

## Ограничения вне omelette-рантайма

- `<image-slot>` вне редактора Claude доступен только для просмотра — если у
  слота нет `src`, перетащить своё изображение и сохранить его не получится
  (нет `window.omelette.writeFile` для записи в `.image-slots.state.json`).
  Слоты с уже подключённым `src` (см. выше) показывают картинку и без этого.
- `support.js` помечен как `GENERATED... do not edit` — это вендоренный
  рантайм, а не код приложения; редактировать его вручную не нужно, при
  необходимости обновить — просто заменить файл целиком.

## История проверок

При первой загрузке версии прототипа находил и чинил структурные баги
HTML — сломанную вложенность `<div>`, задвоенный незакрытый `<sc-if>`,
и `shop`, ошибочно лишённый кнопки «назад». Версия от 2026-08-05 (текущая)
пришла уже без этих проблем — `<sc-if>`/`<div>` сбалансированы по всему
файлу и по каждому блоку экрана отдельно, и `shop` кнопку «назад» показывает.
