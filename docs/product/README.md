# Продуктовая документация Луми

Этот раздел собирает всю продуктовую документацию проекта: видение продукта, границы MVP, полный список функций, контент курсов, экономику геймификации и протокол кризисных ситуаций. Документы перенесены из Google Drive, названия файлов приведены к единому стилю; исходное содержимое не менялось.

## Документы

- **`Lumi_PRD.pdf`** — PRD (product requirements document): продуктовое видение, целевая аудитория и общая концепция приложения.
- **`Lumi_Project_Handover.docx`** — вводный документ для нового руководителя проекта: сводка всех принятых на сегодня решений по продукту, контенту и разработке. Полезен как быстрый ввод в контекст.
- **`Lumi_MVP_Scope.docx`** — документ фиксации объёма первой версии (v1.0): что входит и что не входит в MVP — контент, онбординг, геймификация, маскот, безопасность, платформа.
- **`Lumi_Feature_List.docx`** — полная таблица функций продукта. Обновлено 2026-08-05: помимо F1–F19 добавлены F20–F29 — F21 карточка «Мысль дня», F22 кастомизация/гардероб, F23 обязательная регистрация через Sign in with Apple (без опции пропуска), F24 iOS-виджет (2 состояния), F26 режим «Дыхание» (4-7-8), F27 «Аффирмации», F29 «Медитация» (требует лицензированных аудио-ассетов). F20/F25 (короткие практики-плитки на главном) в этой версии явно **исключены** из главного экрана — контент остаётся в `Lumi_Course_Content.docx` как резерв для v1.1+.
- **`Lumi_Functional_Requirements.docx`** — детальные функциональные требования по каждой фиче из списка выше. Обновлено 2026-08-05 вместе с Feature List.
- **`Lumi_Acceptance_Criteria.docx`** — чек-лист приёмочных критериев для QA перед релизом. Обновлено 2026-08-05.
- **`Lumi_App_Structure.docx`** — карта экранов и навигации приложения. Обновлено 2026-08-05.
- **`Lumi_Course_Content.docx`** — полный текст всех уроков (4 курса по 5 уроков: «Основы самооценки», «Работа с внутренним критиком», «Самосострадание», «Самопринятие»).
- **`Lumi_Gamification_Economy.docx`** — экономика геймификации: валюта «Люмены», XP, уровни, магазин, механика non-punitive streak. Содержит разбор рисков и проверку психологом на манипулятивность. Обновлено 2026-08-05.
- **`Lumi_Crisis_Protocol.docx`** — протокол определения кризисных состояний пользователя (тревога, самообесценивание, суицидальные мысли) и список проверенных номеров горячих линий для региона СНГ. **Важно:** номера линий помощи требуют повторной верификации перед каждым релизом — документ явно это оговаривает.
- **`Lumi_Dev_Plan.pdf`** — верхнеуровневый план разработки из 10 этапов.
- **`Lumi_Strategy_Draft.pdf`** — более ранний альтернативный черновик стратегии: варианты нейминга, позиционирования и личности маскота. Заменён решениями, зафиксированными в `Lumi_Project_Handover.docx`; сохранён для истории.

## `lumi_docs_combined_2026-08-05.txt`

Более ранний снимок всех продуктовых документов, сведённых в один текстовый файл. 5 из 6 обновлённых 2026-08-05 `.docx`-файлов (Feature List, Functional Requirements, Acceptance Criteria, App Structure, Gamification Economy, MVP Scope) теперь **актуальнее** этого снимка — он оставлен только как исторический референс. `Lumi_Course_Content.docx`, `Lumi_Crisis_Protocol.docx`, `Lumi_PRD.pdf`, `Lumi_Dev_Plan.pdf`, `Lumi_Strategy_Draft.pdf` и `Lumi_Project_Handover.docx` в этот раз не обновлялись — если в них нужны свежие детали по F20+, сверяйся с этим файлом.
