# Lumi

Луми — мобильное приложение для развития здоровой самооценки через короткие ежедневные занятия, оформленные в духе Duolingo (геймификация, серии, маскот-компаньон). Контент опирается на подходы КПТ (CBT), терапии принятия и ответственности (ACT) и практики самосострадания.

Приложение **не является терапией и не занимается диагностикой** — только формированием здоровых привычек мышления и эмоциональной поддержкой. Целевой регион — СНГ, язык интерфейса и контента — русский. Разработка ведётся нативно под iOS (Swift/SwiftUI).

## Разработка

Разработка приложения ведётся с использованием Claude Code. Проект собирается только на macOS в Xcode — этот репозиторий может быть подготовлен и на Linux/в облачной среде, но открыть и запустить приложение можно только на Mac.

### Первый запуск

1. Установи [Xcode](https://apps.apple.com/app/xcode/id497799835) (15.4+, iOS 17 SDK) и [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`.
2. В корне репозитория выполни `xcodegen generate` — это создаст `LumiApp.xcodeproj` из `project.yml`.
3. Открой `LumiApp.xcodeproj` и выбери симулятор iOS 17+.
4. Запусти таргет `LumiApp` (⌘R).

`.xcodeproj` не коммитится — после любого изменения `project.yml` (новые файлы, таргеты, настройки) перегенерируй проект командой `xcodegen generate`.

### Что уже готово, а что нет

Реализованы: онбординг (F1–F4, F23), 3 вкладки навигации, курсы и уроки с 15 механиками упражнений (F6–F9), практики «Дыхание»/«Аффирмации»/«Медитация» (F26/F27/F29), профиль, статистика, достижения, магазин, гардероб, уведомления (F17/F32), кризисный экран (F18) и три виджета (F24).

Визуальный слой перенесён из дизайн-репозитория `lumidesign` — тёмная «космическая» тема, иконки Phosphor, кастомный таб-бар, реальные позы маскота. Подробности и правила: [`docs/design/README.md`](docs/design/README.md).

**Список кризисных триггер-паттернов не хранится в репозитории** (см. `LumiApp/Core/Crisis/README.md`) — это осознанное решение по конфиденциальности из `Lumi_Crisis_Protocol.docx`, а не недосмотр.

Код готовится в среде без Xcode, поэтому единственная проверка сборки — CI (`.github/workflows`): на каждый pull request `macos-15` генерирует проект и гоняет `xcodebuild test`. Зелёный CI означает, что оба таргета компилируются и тесты проходят; как экраны выглядят на реальном симуляторе, проверяется только руками.

Прогнать тесты локально: `xcodegen generate`, затем

```
xcodebuild test -project LumiApp.xcodeproj -scheme LumiApp \
  -destination 'platform=iOS Simulator,name=iPhone 16'
```
